# CNN-Image-Classification-App

Моя выпускная квалификационная работа 2020 года. Загружена в архивный целях.

## Цель и задачи
Цель - разработать приложения для классификации изображений внутри директории на основе нейронной сети.

Задачи:
1. провести обзор существующих моделей нейронных сетей;
2. спроектировать нейронную сеть для классификации изображений;
3. разработать приложение для классификации изображений на основе полученной нейронной сети.

## Этапы работы
Работа состояла из следующих этапов:
- Обзор существующих моделей нейронных сетей. Выявление наиболее подходящей модели для достижения поставленной цели.
- Подготовка собственного набора данных для обучения сверточной нейронной сети. Аугментация полученного набора.
- Подбор и оптимизация параметров будущей модели при помощи библиотеки Keras Tuner. Построение сверточной нейронной сети по подобранным параметрам.
- Обучение и тестирование полученной модели сверточной нейронной сети.
- Разработка приложения на основе обученной модели.

## Результаты работы
В результате работы были проанализированы различные модели нейронных сетей. На основе проведенного анализа выбрана, смоделирована и обучена сверточная нейронная сеть для задачи классификации изображений. Также был проведен анализ известных фотобанков для выявления наиболее популярных классов изображений, в результате анализа был подготовлен и расширен путем аугментации собственный набор данных, на котором проходило обучение построенной модели.

В результате выполнения выпускной квалификационной работы было разработано приложение с пользовательским интерфейсом, работа которого основана на сверточной нейронной сети. Приложение проводит классификацию внутри указанной директории, сортируая все изображения по шести папкам: animals, architecture, nature, food, car, people. Изображения, не принадлежащие ни одному из классов, помещаются в подпапку "other".
